Where the boxes are

Run it yourself

Everything here comes from one Java program on the harvest-signal-experiment branch. Run it in PowerShell from the project folder. The first run downloads every round, which takes about 10 minutes per round. It prints a line as each date finishes. Later runs reuse the saved data.

cd "C:\Programming Projects\qaz-agro-sat"
git fetch
git switch harvest-signal-experiment
git pull
.\mvnw.cmd package
java -jar experiment\target\harvest-signal.jar
start experiment-output\index.html

It writes everything to experiment-output: this page, one folder per round with optical.csv, radar.csv and the photos, and the same results tables printed in the terminal.

The rounds are listed in experiment\runs.csv, the boxes in the fields files, and my photo readings in the photo-readings files. If you disagree with a reading, edit it and rebuild the page in a few seconds:

java -jar experiment\target\harvest-signal.jar --report-only

Until a round has a photo-readings file, the program hides that round's rule results, so the photos can be read without knowing the answer. To download everything again, add --refresh.

Data sources

  • Optical images: Copernicus Sentinel-2 L2A from Earth Search (collection sentinel-2-c1-l2a, tile T41UMV).
  • Radar: Copernicus Sentinel-1, terrain-corrected by Catalyst, from Microsoft Planetary Computer (CC BY 4.0).
  • Rainfall: modelled daily totals from Open-Meteo (CC BY 4.0), for one point in the middle of the area.
