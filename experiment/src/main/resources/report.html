What this does not prove yet

  • The photo dates are my reading, not ground truth. I judged each cut by eye from the satellite photos. Nobody on the ground has confirmed a single date.
  • The rule was tuned on these same fields. I set the jump size ( points) after looking at this data, so it needs testing on fields it has never seen.
  • Six usable fields is a small sample. Three of my twelve boxes were badly placed: two straddle two fields and one control is half a field. That's a good argument for drawing field boundaries automatically.
  • Cloud sets the precision. The photo windows are 8 to 15 days wide, and field F01 was cut during a two-month run with no clear photo. Optical satellites alone can only date the cut to within a week or two.
  • The radar test was basic. It mixed the two orbits, which look from different angles, and didn't correct for rain. Radar isn't ruled out, but it showed nothing useful in this form.

Run it yourself

Everything here comes from one Java program on the harvest-signal-experiment branch. Run it in PowerShell from the project folder. The download takes about 7 to 10 minutes and prints a line as each date finishes.

cd "C:\Programming Projects\qaz-agro-sat"
git fetch
git switch harvest-signal-experiment
.\mvnw.cmd package
java -jar experiment\target\harvest-signal.jar
start experiment-output\index.html

It writes everything to experiment-output: this page, the numbers as optical.csv and radar.csv, the photos, and the same results table printed in the terminal.

If you disagree with how I read a photo, edit experiment\photo-readings.csv and rebuild the page from the saved data in a few seconds:

java -jar experiment\target\harvest-signal.jar --report-only

The boxes are in experiment\fields.csv, as pixels on the July map. If you move a box, run the full download again.

Data sources

  • Optical images: Copernicus Sentinel-2 L2A, 2025, from Earth Search (collection sentinel-2-c1-l2a, tile T41UMV).
  • Radar: Copernicus Sentinel-1, terrain-corrected by Catalyst, from Microsoft Planetary Computer (CC BY 4.0).
  • Rainfall: modelled daily totals from Open-Meteo (CC BY 4.0), for one point in the middle of the area.
  • Regional harvest progress: inbusiness.kz on 4 September, 1 October and 16 October 2025, citing the oblast's agriculture department. The 1 October article doesn't say which day its figure is for.
